      API の接続設定
      
    
        Jev の API はブラウザからの直接呼び出しを CORS で拒否するため、間に中継サーバーが要ります。
        Cloudflare Workers で配信している場合は同じサーバーの /jev を自動で使うので設定は不要です。
        中継の無い静的ホスティング（GitHub Pages など）では、キーワードベースのデモモードになります。
        別に立てた中継を使いたいときだけ URL を入れてください。
